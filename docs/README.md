# Rayzan Documentation

Rayzan is a local-first multi-agent debate and orchestration tool. It removes the manual copy/paste work of coordinating a Coordinator, multiple Watchers, and a Coder.

It exists so the Operator can run structured debates without reconstructing context by hand, while keeping semantic judgment with the Coordinator and mechanical protocol enforcement with the Orchestrator.

This directory is the project record. These files are maintained as the project changes: new work is listed in `TASKS.md`, accepted decisions are appended to `DECISIONS.md`, architecture changes update `ARCHITECTURE.md`, and `STATUS.md` always reflects the current state. Documents must not claim something is implemented until it actually is.

| [DECISIONS.md](DECISIONS.md)       | Append-only record of accepted product and architecture decisions                           |
